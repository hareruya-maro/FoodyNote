## **2\. 画面一覧詳細**

### **S01: ログイン・オンボーディング (Auth)**

* **アプリ名表示:** 「Foody Note」ロゴ。  
* **キャッチコピー:** 「お腹の不調の原因を、写真で探そう」  
* **免責事項:** 診断機器ではない旨の同意。

### **S02: ホーム・タイムライン (Home)**

* **ヘッダー:** 「Foody Note」  
* **タイムライン:** 食事画像（サムネイル複数枚）、体調記録の時系列表示。  
* **Double FAB:** 右下に「食事記録」「体調記録」ボタンを常駐。

### **S03: 食事記録フロー (Meal Entry)**

* **S03-1:** 複数枚の写真を選択・撮影可能。  
* **S03-2:** AIによる一括解析結果を表示。全画像から統合されたタグ（成分）リストを編集・保存。

### **S04: 体調記録モーダル (Symptom Entry)**

* 症状アイコン、重症度、メモをワンタップ感覚で記録。

### **S05: 履歴カレンダー (History/Calendar)**

* 月カレンダー表示。不調があった日を強調表示。

### **S07: 分析レポート (Analysis)**

* **不調トリガーランキング:** 「不調発生のX時間前によく摂取していた食材」をランキング表示。  
* 常食（水、米など）を除外するロジックを含む。

### **S08: 設定・マイページ (Settings)**

* **医師提示モードボタン:** S09へ遷移する目立つボタンを配置。  
* データエクスポート、アカウント管理。

### **S09: 医師提示モード (Doctor Presentation View)**

* **目的:** 診察室での提示専用。  
* **UI:** ナビゲーションバー非表示（フルスクリーン）。誤操作防止。  
* **表示内容:**  
  1. 患者ID・期間  
  2. ハイライト（不調回数、平均タイムラグ）  
  3. AI分析サマリー（不調時の共通食材TOP3）  
  4. 食材別相関テーブル  
  5. 詳細エピソードログ（時系列リスト）

## **3\. UI/UX デザイン方針**

* **Color:**  
  * Primary: Teal (\#009688) \- 清潔感  
  * Accent: Coral (\#FF7F50) \- 注意・不調  
* **Layout:**  
  * Web版でもスマホライクな「中央寄せシングルカラム（最大幅480px）」を採用し、開発工数を削減。
