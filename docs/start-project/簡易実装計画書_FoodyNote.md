# **簡易実装計画書**

## **プロジェクト：Foody Note (フーディノート)**

**作成日:** 2026年1月15日

## **全体方針**

ハッカソンでの開発効率を重視し、Turborepo を用いたモノレポ構成でプロジェクトを開始する。  
開発は3段階のフェーズ（UIモック → ロジック → バックエンド）で進行し、各段階で人間によるレビューを行う。

## **Phase 1: UIモックアップとルーティング**

* **目標:** 見た目と遷移の完成。  
* **タスク:**  
  * Monorepo環境構築 (apps/app \+ packages/ui)。  
  * Expo SDK 54 \+ NativeWind v5 セットアップ。  
  * 全画面 (S01〜S09) の静的実装。  
  * Expo Routerによる画面遷移実装。  
* **🛑 Human Review 1:** デザイン・遷移の確認。

## **Phase 2: フロントエンドロジック実装**

* **目標:** ダミーデータで「動く」状態にする。  
* **タスク:**  
  * Jotai導入。  
  * 食事・体調データのMock JSON作成。  
  * AI解析のMock化（画像選択後、固定タグを返す処理）。  
  * 「不調トリガーランキング」の計算ロジック実装。  
  * 医師提示モードへのデータ受け渡し実装。  
* **🛑 Human Review 2:** 操作感、分析ロジックの妥当性確認。

## **Phase 3: バックエンド連携・本番実装**

* **目標:** 実データ・実AIで動作させる。  
* **タスク:**  
  * Firebase接続 (Auth, Firestore, Storage)。  
  * TanStack Queryによるデータフェッチ実装。  
  * **Google Gemini API** 連携（Mock廃止、実画像解析）。  
  * PWA設定、Firebase Hostingへのデプロイ。  
* **🛑 Human Review 3:** データ保存、AI精度の最終確認。
